# 학교 등산 행사 지도

Streamlit과 Folium을 이용한 학교 등산 행사 지도 서비스입니다. 코스를 선택하면 해당 등산로의 지점, 연결 경로, 코스 안내와 주의사항을 확인할 수 있습니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run main.py
```

앱은 `main.py`를 진입점으로 사용합니다. 실행하면 지도 페이지가 기본으로 열립니다.

## 현재 기능

- 지도 페이지와 산행 안내 페이지를 사이드바 버튼으로 이동
- 모든 페이지에서 동일한 공통 사이드바 사용
- 코스 선택 메뉴에서 `A`, `B`, `C`, `D`, `E` 중 하나 또는 `전체 코스 보기` 선택
- 코스 선택 기본값은 A코스
- 선택한 코스의 지점 마커 표시
- 선택한 코스의 등산로 연결선 표시
- 지도 타일 변경 및 지도/마커/연결선 표시 설정
- 마커 클릭 시 지점명, 코스명, 이미지 팝업 표시
- 지도 오른쪽에 코스별 소요시간, 안내 문구, 주의사항 표시
- 지도 아래에 코스별 지점 사진을 닫힌 expander로 표시
- 산행 안내 페이지에 이용 방법, 코스 정보, 안전 수칙, 출발 전 확인 사항 제공

## 파일 구조

- `main.py`: Streamlit 페이지 라우터. `map_page.py`를 기본 페이지로 등록
- `map_page.py`: 지도, 코스 안내, 지점별 사진 영역 표시
- `map.py`: Folium 지도 생성, 마커와 등산로 연결선 생성, 코스 정보 관리
- `sidebar.py`: 모든 페이지에서 사용하는 공통 사이드바와 코스 선택 처리
- `info_page.py`: 서비스 이용 방법과 산행 안내 페이지
- `PathMap.csv`: 코스, 위치명, 좌표, 소요시간, 이미지 URL 데이터
- `images/`: 저장소에 보관된 지점 이미지 파일

## 이미지 경로

`PathMap.csv`의 `이미지` 열은 공개 GitHub 저장소의 Raw URL을 사용합니다.

```text
https://raw.githubusercontent.com/mmmmmmseong/map/main/images/A입구.jpg
```

따라서 이미지 파일을 추가하거나 이름을 변경할 때는 다음을 함께 확인해야 합니다.

- GitHub의 `images/` 폴더에 파일이 올라가 있는지
- CSV의 이미지 URL과 실제 파일명이 정확히 일치하는지
- 저장소와 `main` 브랜치가 공개 상태인지
- 이미지 파일명에 한글, 숫자, 쉼표가 포함될 경우 CSV에서 필요한 따옴표가 적용됐는지

## 작업 진행 순서

1. 기존 `main.py`의 페이지 선택 라디오 구조를 확인하고, 지도 화면을 기본으로 유지하면서 산행 안내 페이지 이동 기능을 추가했습니다.
2. `st.page_link("main.py")` 사용 시 현재 실행 중인 진입 파일이 페이지 레지스트리에 없어 `KeyError`가 발생하는 문제를 확인했습니다.
3. `st.switch_page()`만 사용하는 방식에서 발생할 수 있는 페이지 인식 문제를 해결하기 위해 `st.navigation`에 지도와 안내 페이지를 명시적으로 등록했습니다.
4. 지도 화면을 `map_page.py`로 분리하고 `main.py`를 페이지 라우터 전용 파일로 정리했습니다.
5. 지도 페이지와 안내 페이지가 같은 메뉴를 사용하도록 `sidebar.py`를 새로 만들고 공통 사이드바를 적용했습니다.
6. 사이드바 페이지 이동 버튼의 간격, 높이, 패딩, 정렬과 hover 스타일을 통일했습니다.
7. 사용자의 요청에 따라 페이지 라벨과 expander 구분선 및 추가 간격 스타일은 제거하고 버튼 스타일만 유지했습니다.
8. 지도 마커 클릭 정보를 이용해 선택 지점 사진을 지도 아래에 표시하는 초기 방식을 구현했습니다.
9. 사진을 지도 아래가 아니라 마커 클릭 팝업에 표시하도록 Folium 마커 팝업 방식으로 변경했습니다.
10. 지도 오른쪽에 선택 코스별 주의사항을 표시하고, 지도를 줄인 2열 레이아웃을 구성했습니다.
11. 코스 선택을 여러 토글에서 단일 `selectbox` 방식으로 변경하고 `전체 코스 보기` 옵션을 추가했습니다.
12. 코스 목록을 `PathMap.csv`에서 자동으로 읽도록 변경하고 기본 선택값을 A코스로 설정했습니다.
13. 코스 expander를 제거해 코스 선택 메뉴가 사이드바에 항상 보이도록 수정했습니다.
14. 코스 선택이 본문에 표시되는 오류를 `st.sidebar.selectbox()`로 수정했습니다.
15. 서비스가 공개 GitHub 저장소에서 이미지를 불러올 수 있도록 `PathMap.csv`에 `이미지` 열을 추가했습니다.
16. 이미지 파일 경로를 저장소 상대 경로에서 GitHub Raw URL로 변경했습니다.
17. 지도 코드가 이미지 경로를 자동 조합하지 않고 CSV의 `이미지` 열을 직접 사용하도록 수정했습니다.
18. 지도 오른쪽 정보 영역에 코스별 안내 문구, 예상 소요시간, 주의사항과 지점별 사진 목록을 추가했습니다.
19. 지점별 사진 목록을 기본 닫힘 expander로 변경하고, 지도와 안내 영역 아래의 별도 전체 너비 구역으로 이동했습니다.
20. 모든 코스에서 같은 위치에 겹치는 정상 마커를 A코스 하나로 통합하는 시도를 적용했다가, 사용자의 요청에 따라 제거했습니다. 현재는 선택된 코스별 정상 마커가 각각 표시됩니다.
21. 이미지 표시 방식에서 캐싱과 Base64 방식 등을 시험했으나 최종적으로 제거하고, 현재는 CSV의 GitHub Raw URL을 팝업과 사진 영역에서 직접 사용합니다.

## 요청 외 추가 작업 기록

아래 항목만 사용자의 기능 요청과 별도로 작업 과정에서 수행한 내용입니다. 페이지 분리, 공통 사이드바, 코스 선택, 이미지 표시, 정보 영역, 안내 페이지 등은 사용자가 요청한 사항이므로 이 목록에서 제외했습니다.

- Streamlit 오류 로그를 확인해 `page_link`와 `switch_page`가 페이지 레지스트리와 맞지 않을 때 발생하는 `KeyError`의 원인을 진단했습니다.
- 파일을 수정하기 전에 현재 파일 내용과 사용자가 되돌린 변경 사항을 확인했습니다.
- 수정 후 관련 Python 파일에 대해 `py_compile` 문법 검사를 수행했습니다.
- VS Code 진단으로 import, 문법, 페이지 구조 오류를 확인했습니다.
- pandas로 `PathMap.csv`를 다시 읽어 행 수, 열 수, 이미지 URL 형식을 검증했습니다.
- 위치명에 쉼표가 포함된 CSV 행이 정상적으로 파싱되는지 확인하고 CSV 따옴표 형식을 보정했습니다.
- Git 원격 저장소와 기본 브랜치를 확인해 공개 GitHub Raw 이미지 URL의 저장소명과 브랜치를 확인했습니다.
- Folium 지도 HTML에 CSV의 이미지 경로가 실제로 포함되는지 확인했습니다.
- README에 현재 기능, 파일 구조, 이미지 경로 규칙, 작업 순서를 문서화했습니다.

캐싱, Base64 이미지, 정상 마커 통합 등은 제가 임의로 계속 남긴 기능이 아니라, 대화 중 요청에 따라 적용·수정·삭제한 시도입니다.

## 현재 동작 주의사항

- Streamlit은 위젯을 조작할 때 페이지 전체를 다시 실행합니다.
- GitHub Raw 이미지 URL은 저장소에 파일이 실제로 존재하고 공개되어 있어야 합니다.
- `전체 코스 보기`에서는 같은 좌표의 정상 마커가 코스별로 겹칠 수 있습니다. 현재는 코스별 마커를 유지하는 상태입니다.
- 이미지 URL이 잘못되었거나 파일이 없으면 브라우저에 깨진 이미지 아이콘이 표시될 수 있습니다.
